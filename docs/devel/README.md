## 技术栈说明

### 前端技术
- **Vue 3**: 响应式前端框架
- **TypeScript**: 类型安全的JavaScript
- **Pinia**: 状态管理
- **Vite**: 构建工具和开发服务器
- **Axios**: HTTP客户端
- **SCSS**: CSS预处理器

### 后端技术
- **Spring Boot 3**: Java后端框架
- **WebFlux**: 响应式编程
- **Jsoup**: HTML解析器
- **Hutool**: Java工具库
- **GBase**: 数据库

### 部署技术
- **Docker**: 容器化
- **Kubernetes**: 容器编排
- **Helm**: Kubernetes包管理器
- **Jenkins**: CI/CD工具

详细的开发环境配置请参考项目根目录的 `CLAUDE.md` 文件。

## 架构特点

1. **前后端分离**: Vue前端 + Spring Boot后端
2. **响应式设计**: 适配不同屏幕尺寸
3. **模块化音乐源**: 易于扩展其他平台
4. **流式音频播放**: 无需下载完整音频
5. **自动部署**: CI/CD自动化流程

## 主要功能

- B站音乐搜索
- 音频在线播放
- 播放控制（上一首、下一首、暂停/播放）
- 音量控制
- 播放模式（顺序、随机、单曲循环）
- 响应式UI设计
